# Charm School – Daily Routine Tracker

A single-page app for tracking a daily routine: 15 minutes of study and 15 minutes of workout, every day since 26 August 2026.

- Open `index.html` in a browser, or enable GitHub Pages on this repo to host it.
- Days from 26 Aug up to yesterday are pre-filled as done on first open. Only today can be ticked; past days are locked.
- Shows completion %, current and longest streak, total study and workout time, and a calendar view.
- Data is stored in the browser (localStorage) and can be downloaded as JSON. The lock is browser-side only, so clearing site data resets it.
